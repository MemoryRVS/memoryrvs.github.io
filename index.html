Python · OCR · OpenCV

Автоскуп предметов STALZONE

Полноценная десктопная утилита с GUI на CustomTkinter. В реальном времени захватывает заданную область экрана, распознаёт цены через Tesseract OCR, и если цена ниже заданного порога — мгновенно выкупает лот: клик по лоту, кнопка «Выкупить», подтверждение. Реакция — за доли секунды.

  • Захват экрана через mss + обработка OpenCV для точного OCR
  • Два алгоритма распознавания: быстрый (image_to_data) и запасной (cv2.findContours)
  • Настраиваемые ROI, точки кликов, задержки и диапазон цен — прямо в GUI
  • Непрерывный режим: после покупки сразу переходит к следующему лоту
  • Глобальная горячая клавиша остановки (по умолчанию F8), настраивается
  • Лог действий в реальном времени + предпросмотр экрана с выделением ROI

Python · Discord.py · FFmpeg

Discord Music Bot

Полноценный музыкальный бот для Discord с очередью, плейлистами и сохранением настроек для каждого сервера. Работает через yt-dlp как pipe-источник для FFmpeg — обходит SABR и стабильно стримит даже там, где обычные боты падают.

  • Воспроизведение по ссылке или поисковому запросу (ytsearch)
  • Поддержка плейлистов с ограничением очереди (защита от спама)
  • Управление: skip, pause, resume, stop, shuffle, remove, clear
  • Loop текущего трека, сохранение громкости и loop per-guild
  • Автоотключение, когда в канале не остаётся живых людей
  • Auto-reconnect и retry при обрывах стрима (60 попыток переподключения)
  • Конфиг каждого сервера хранится в JSON и переживает перезапуск

FunPay API — библиотека для FunPay.com

Полноценная Python-обёртка над веб-интерфейсом FunPay: работа с лотами, заказами, чатом, балансом и выводом средств. Берёт на себя CSRF-токены, куки, парсинг HTML и все тонкости внутреннего API маркетплейса.

  • Создание, редактирование и удаление лотов с авто-поиском ID
  • Проверка оплаты заказов в реальном времени с колбэком on_paid
  • Полноценный чат: чтение контактов, получение сообщений, отправка текста
  • Получение баланса по всем валютам и вывод средств с поддержкой 2FA
  • Автоматическое извлечение CSRF-токена из 5 разных источников
  • Хранение сессии в requests.Session — быстрые повторные запросы
